# Employee-salary-analysis
Employee Salary Analysis project using Python, Pandas, and Matplotlib. Includes data analysis and visualization of department-wise salaries.


## Project Overview
This project analyzes employee salary data using Python.

## Tools Used
- Python
- Pandas
- Matplotlib

## Analysis Performed
- Average Salary
- Highest Salary
- Lowest Salary
- Department-wise Salary Analysis

## Visualization
- Bar chart for department-wise salary
